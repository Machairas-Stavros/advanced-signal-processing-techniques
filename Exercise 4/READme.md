This is the fourth exercise of the subject dealing with Cepstrum via Homomorphic Filtering.

First step is to acquire voice samples of a male and a female person making the five vowel sounds – “a”, “e”, “i”, “o”, “u”.
To do so the "recording.m" file is used, producing audio recording files for the corresponding sounds. Afterwards, those files are merged (using a function not provided here) to produce a matrix containing the desired information about all the voice signals for the male and the female voice respectively.
Those information are saved into the "male_voice.mat" and "female_voice.mat" archives and loaded into the "demo.m" for the deomnstration process.    

"code" folder contains a demonstration file for the exercise, and all helper functions needed, except the matrices containing information about the voice samples (for privacy reasons). 

"plots" folder contains images derived from the executed experiments used in the report of the exercise.
